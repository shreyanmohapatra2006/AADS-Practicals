
**AADS PRACTICALS – TIME COMPLEXITIES**

**1. RANDOMIZED QUICK SORT**

   Best Case:    O(n log n)
   
   Average Case: O(n log n)

   Worst Case:   O(n^2)
   
   Space:        O(log n) average recursion stack

**2. RANDOMIZED SELECT**

   Best Case:    O(n)
   
   Expected:     O(n)
   
   Worst Case:   O(n^2)
   
   Space:        O(n) worst-case recursion stack

**3. KRUSKAL'S ALGORITHM**

   Time:         O(E log E)
   
   Space:        O(V + E)

**4. BELLMAN-FORD ALGORITHM**

   Time:         O(V * E)
   
   Space:        O(V)

**5. B-TREE**

   Searching:   O(log n)
   
   Insertion:   O(log n)
   
   Traversal:   O(n)
   
   Space:       O(n)

**6. KMP STRING MATCHING**

   LPS Construction: O(m)
   
   Searching:        O(n)
   
   Total Time:       O(n + m)
   
   Space:            O(m)

**7. SUFFIX TRIE**

   Construction: O(n^2)
   
   Searching:    O(m)
   
   Space:        O(n^2)


**NOTATIONS:**
n = Number of elements / length of text
m = Length of pattern
V = Number of vertices
E = Number of edges
